# archived debian setup

![Archived](https://img.shields.io/badge/status-archived-red)

Setup a debian box using a json configuration.

This repository is an archival record of my Debian 12 laptop and home server setups.

This is meant as a personal reference and historical archive, not as a guide to replicate exactly. Some decisions reflect my specific workflow and preferences.

Some of the design choices, package selections, and security considerations documented here have influenced or persisted in my current setups. This archive shows the evolution of my workflow and configuration philosophy.

An example configuration file is provided [here](./config.json).
